# 金色手势圣诞树 v17.6

可直接在手机浏览器打开的静态网页。Three.js、MediaPipe、WebAssembly 和手部模型均随站点文件一起发布，页面启动不依赖外部 CDN。点击“开启手势”才会请求摄像头权限，摄像头画面始终隐藏。

此页基于 [liq47317-boop/christmas-tree-v17.6](https://github.com/liq47317-boop/christmas-tree-v17.6) 的 HTML 修改。该 fork 未单独附许可证；其上游项目 [Roisten/Romantic-Christmas-Tree](https://github.com/Roisten/Romantic-Christmas-Tree) 提供 Apache 2.0 许可证。Three.js 为 MIT，MediaPipe Tasks Vision 为 Apache 2.0，相关文本见仓库内的许可证文件。
